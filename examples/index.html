dashboard-toolkit examples

  • Sensor site — a schematic with sensor markers, the simulator source, derived tiles, a weather card and the area banner. The pattern behind offshore-platform-monitor and well-site-monitor.
  • Well pad — an overhead view of one oil well on private land: pumping unit, tank battery, gate sensor, solar ESP32 emissions nodes and a Raspberry Pi gateway. Built to teach: a guided tour, scenario stories, device cutaways and public-record explainers.
  • Release matrix — workflow events (builds, deploys, tests) in a components × environments matrix. The pattern behind the release dashboard.
  • Live service — fetches from a real HTTP service by REST polling or Server-Sent Events, with alerts managed by the server. Start it with npm run mock-server.
